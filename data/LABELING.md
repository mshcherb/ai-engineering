# Правила розмітки golden set

`data/golden.json` — 15 текстів, розмічених вручну. Це еталон, з яким порівнюються відповіді моделей.

## Як розмічати
1. Читай `text` і заповнюй `label` **сам, не дивлячись на відповідь моделі** в `results/`.
2. Сумнівний випадок вирішуй за правилами нижче й коротко записуй, чому так, у `notes`.
3. Поле `text` — лише для зручності, при оцінюванні воно не використовується.

## Поля
| поле | значення |
|---|---|
| `language` | `uk` / `ru` / `en` / `mixed` / `unknown` |
| `is_about_stocks` | `true`, якщо текст про конкретні цінні папери або фінансові ринки |
| `mentions` | усі компанії / цінні папери; `[]`, якщо немає |
| `summary` | одне речення російською (не оцінюється) |

Кожна згадка (`mentions[]`):

| поле | значення |
|---|---|
| `company` | як названо в тексті |
| `ticker` | нормалізований тикер (`NVDA`); `null` для приватних і невідомих |
| `asset_type` | `stock` / `etf` / `index` / `crypto` / `private` / `other` |
| `sentiment` | `bullish` / `bearish` / `neutral` / `mixed` |
| `reasoning` | чому автор так вважає, коротко; `null`, якщо причини немає (не оцінюється) |
| `price_target` | число, тільки якщо явно названа цільова ціна; інакше `null` |
| `horizon` | `short` (дні–тижні) / `medium` (місяці) / `long` (рік+) / `unknown` |
| `quote` | точна цитата з тексту (не оцінюється) |

## Правила
- **Розмічаємо лише за текстом.** Модель бачить тільки `text`: картинки, контекст чату й власні знання розмітника не враховуються.
- **Розмічаємо думку автора, а не свою.** Власні інвестиційні ідеї — у `notes`.
- **Новина або факт без думки автора** (зокрема переказ рекомендації аналітиків) → `neutral`.
- **Сарказм** оцінюється за змістом, а не за словами.
- **Звіт «beats» / «misses»** без коментаря автора → `bullish` / `bearish` за знаком, яким позначив автор (📈 / 📉); 🤔 → `mixed`; без позначки → `neutral`.
- **Згадано, щоб виключити** («ні, я не про $LVMH») → згадка лишається, `neutral`.
- **Країна, сектор, «банки», «ринок», «фонди» загалом, нерухомість** — не конкретний цінний папір, у `mentions` не потрапляє.
- **Компанія до IPO** (зокрема, якщо текст прямо каже «pre-IPO») → `private`.
- **Індекс** (S&P 500, KOSPI) → `asset_type: index`, тикер — якщо є загальновживаний (`SPX`), інакше `null`.
- **Приватна компанія** (Anthropic, OpenAI, SpaceX) → `asset_type: private`, `ticker: null`.
- **Конкретний фонд / ETF / closed-end fund** → `etf`.
- **`horizon`** — тільки якщо термін названо або він очевидний («тримаю до літа» → `medium`), інакше `unknown`. Момент входу («завтра на відкритті») — не горизонт.
- **`language: unknown`** — якщо слів немає (лише емодзі).
- **`price_target`** — тільки явна ціль. Поточна ціна, ціна покупки, прибуток не рахуються. Валюта не вказується, лише число.
- Одна компанія згадана кілька разів → **одна** згадка з загальною думкою; якщо думки протилежні → `mixed`.

## Що оцінюється
- `is_about_stocks`, `language` — збіг.
- Набір компаній: precision (не вигадала зайвих) і recall (знайшла всі). Зіставлення за `ticker`, а якщо його немає — за назвою.
- Для збіглих компаній: `sentiment`, `asset_type`, `horizon`, `price_target`.

Не оцінюються: `company` (написання), `reasoning`, `quote`, `summary`.
